# Гамбит 67

Шахматы с аркадными испытаниями для Windows 10/11 x64. Установите `dist/Gambit67-1.6.2/Gambit67-Setup.msi` и откройте **Gambit 67** из меню «Пуск». Для запуска без установки есть `dist/Gambit67-1.6.2/Gambit67.exe`.

## За доской

Выберите компьютер, игру вдвоём за одним ПК или LAN. Щёлкните фигуру, затем подсвеченную клетку. При превращении пешки выберите q, r, b или n. Доступны рокировка и взятие на проходе. Партия завершается матом, патом, при недостатке материала, пятикратном повторении или после 75 ходов каждой стороны без взятий и ходов пешек.

При включённом QTE только атакующий проходит «Маятник» или «Стекольщик». Взятие засчитывается, если атакующий выжил. Промах отменяет взятие и расходует одну из пяти единиц энергии. На встроенной арене уклоняйтесь от волн стрелками или WASD девять секунд. Столкновение стоит одной единицы энергии. При нуле побеждает соперник.

В главном меню откройте «Настройки». Пять частот от «Очень редко» до «Очень часто» задают интервал от 52–68 до 12–28 секунд. Испытания можно выключить. При включённом лабиринте «Контур» примерно треть случайных событий — сбор точек на время. Больше очков приносит два сердца (до пяти), при равенстве награды нет. Оба игрока участвуют одновременно. Shift ускоряет с инерцией; касание края арены смертельно.

## Локальная сеть

На первом ПК выберите «Создать LAN-стол» и нажмите «Начать партию». На втором выберите «Войти по IP» и введите адрес первого компьютера из окна ожидания. Хозяин играет белыми, гость — чёрными. Ходы и испытания определяет компьютер хозяина. При запросе брандмауэра разрешите игру в частной сети. Используется TCP 41667. При отключении игрока стол закрывается.

## Бои из Undertale Boss Fight

Встроенные арены авторские. Для боёв из [ThakornToon/undertale-boss-fight](https://github.com/ThakornToon/undertale-boss-fight) подключите свою локальную сборку. Адаптер рассчитан на ревизию `499722735b81b0ea2c8e4586e88d08e4178cc494`. Java-код проекта предоставляется по MIT, игровые материалы имеют отдельные условия. [Лицензия проекта](https://github.com/ThakornToon/undertale-boss-fight/blob/main/LICENSE).

1. Подготовьте исходники проекта и необходимые ресурсы из своей копии игры по инструкции репозитория. В корне проекта выполните `.\gradlew.bat classes`.
2. Укажите JDK, совместимый с этой сборкой, через JAVA_HOME или PATH. В меню «Арены: встроенные» выберите каталог проекта, содержащий `build/classes/java/main/Main.class`.
3. В LAN подключите сборку на обоих компьютерах. Если хотя бы у одного игрока она не выбрана, стол использует встроенные арены.
4. В случайный момент откроется окно боя со случайным боссом. Управление — стрелки, Z и X. По окончании боя игра вернётся к доске. Поражение или закрытие окна стоит одной энергии.

## Сборка

На Windows с Python 3.12 x64 (включая Tcl/Tk и pip) выполните `.\build.ps1`. Результаты появятся в `dist`. Готовая игра запускается без Python. MSI устанавливает её в профиль пользователя, создаёт ярлык в «Пуск» и поддерживает удаление через настройки Windows.

Для пересборки комплектного интерфейсного класса используйте JDK 17+ и скомпилированный внешний проект:

```powershell
javac --release 17 -encoding UTF-8 -cp "C:\Games\undertale-boss-fight\build\classes\java\main" -d src src\GambitEncounter.java
```

Правила реализованы библиотекой [python-chess](https://github.com/niklasf/python-chess). Исходный код Гамбит 67 распространяется по GPL-3.0 или более поздней версии. Текст лицензии в `licenses/chess-GPL-3.txt`.

## Реванш и вызовы QTE

При мате сторона под матом получает бой со случайным боссом. Победа возвращает доску на пять полуходов (или в начало), поражение и закрытие окна фиксируют мат. Энергия и потраченные вызовы сохраняются. За одним ПК передайте управление игроку под матом. При игре с компьютером бой в обоих случаях проходит человек.

Для подключения боёв при мате на другом ПК установите Git и JDK 21+, добавьте Java в PATH и запустите соседний с игрой Setup-Encounters.ps1. Скрипт скачивает и компилирует внешний проект. В LAN подготовьте оба ПК.

Во время хода соперника доступна кнопка «Бросить QTE». У каждого игрока три вызова за партию, между его вызовами должно пройти 60 секунд. Промах расходует энергию цели.

## Шахматный компьютер

В режиме «С компьютером» выберите силу Stockfish 19 перед стартом. Четыре уровня меняют параметр Skill Level и время расчёта хода. Движок входит в поставку и работает без интернета. [Исходники и официальный выпуск](https://github.com/official-stockfish/Stockfish/releases/tag/sf_19).

В меню «Партия» можно предложить бой за энергию. После согласия оба игрока попадают на одну случайную встроенную арену. Первая потеря персонажа завершает бой для обоих, выживший получает 5 энергии. При одновременном поражении энергия сохраняется. За одним компьютером белые используют WASD, чёрные — стрелки.
